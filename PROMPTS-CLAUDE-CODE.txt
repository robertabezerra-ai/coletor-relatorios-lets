ANTES DE ABRIR O CLAUDE CODE
────────────────────────────────────────────────────────────────────────────
1. Crie uma pasta no computador, por exemplo  coletor-lets
2. Copie para dentro dela estes cinco arquivos:
      SPEC-APP-FORMULARIO.md
      perguntas.schema.json
      FORMULARIO-CONSULTOR.docx
      RELATORIO-BASE-2026.html
      GUIA-DE-IDENTIDADE.md
3. Crie uma conta em supabase.com e um projeto novo (região South America).
   Guarde: Project URL, anon key e service_role key.
   Elas ficam em Project Settings › API.
4. Abra o terminal na pasta e rode:  claude
5. Mande a MENSAGEM 1.

Entre uma fase e outra, teste no navegador. Se algo estiver errado, corrija
naquela fase antes de seguir — erro de fundação vira retrabalho em cascata.

 MENSAGEM 1 · Fundação
════════════════════════════════════════════════════════════════════════════

Leia o SPEC-APP-FORMULARIO.md inteiro antes de começar. Ele descreve um app
que vamos construir em oito fases; você vai executar uma fase por vez e parar
no fim de cada uma para eu testar.

Execute agora só a Fase 1 (Fundação):
- Projeto Next.js 15 com App Router, TypeScript e Tailwind.
- Fonte Figtree e as variáveis de cor da LETS configuradas no Tailwind.
- Cliente Supabase para browser e para servidor.
- Login por magic link restrito a @letsmarketing.com.br, validado no cliente
  e no servidor.
- Middleware protegendo todas as rotas menos /login.
- Tela /login seguindo a identidade do GUIA-DE-IDENTIDADE.md.
- Arquivo .env.local.example com as três variáveis.

Não crie tabelas nem telas de formulário ainda. Ao terminar, me diga
exatamente o que preciso fazer no painel do Supabase e da Vercel para isso
rodar, e pare.

 DEPOIS DAS OITO FASES · publicar na Vercel
════════════════════════════════════════════════════════════════════════════

Suba o projeto para um repositório no GitHub, importe na Vercel e cadastre
as três variáveis de ambiente em Settings › Environment Variables:

  NEXT_PUBLIC_SUPABASE_URL
  NEXT_PUBLIC_SUPABASE_ANON_KEY
  SUPABASE_SERVICE_ROLE_KEY

Depois do primeiro deploy, adicione a URL da Vercel em
Supabase › Authentication › URL Configuration › Redirect URLs. Sem isso o
link de acesso por e-mail cai numa página de erro.
